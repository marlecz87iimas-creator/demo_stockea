# Demo Stockea

Demo **solo visual** de Stockea. No se conecta a ningún backend ni a Hildra Core.

## Qué incluye

- Apariencia del panel (dashboard, ventas, inventario, productos, materiales, etc.)
- Datos temporales en memoria del navegador
- Máximo **2** registros por cada opción creable
- Sin login, sin API, sin lógica de negocio real

## Inicio

```bash
npm install
npm run dev
```

Abre la URL de Vite (normalmente `http://localhost:5174`).

## Build

```bash
npm run build
npm start
```
